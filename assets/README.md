# assets/

This prototype uses **no image or sound files**. Every sock, bunny, bubble and wall
is drawn by code (see `scripts/sock_body.gd`, `scripts/block_art.gd`, `scripts/art.gd`).

The only file here is `icon.svg`, the project icon, which is hand-written SVG text.

When you make real art later (PNG sprites, sounds, fonts), put it in this folder.
